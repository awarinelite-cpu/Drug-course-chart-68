Backup All Patients

Downloads every patient's full record (active + closed admissions) as one JSON file, independent of Firestore — for legal/audit purposes or disaster recovery. This runs on demand rather than a fixed schedule (this is a static site with no server to run a true automatic cron job on) — save the file somewhere safe (e.g. Google Drive) and run it on whatever cadence you want, e.g. weekly.
